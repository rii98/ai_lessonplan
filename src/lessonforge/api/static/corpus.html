What is this, and how do I use it?

LessonForge doesn't invent lessons from thin air — it grounds them in a knowledge base you control. The better this corpus, the less generic every generated lesson becomes. This page lets you grow and clean that corpus without touching the command line.

The five collections

  • reference — the actual course material: textbook chapters for a topic. When a lesson's topic is covered here, the AI grounds in this real book instead of its general knowledge. Add whole chapters as Markdown in the Book tab below.
  • curriculum — CDC/NEB standards & learning outcomes. What students must learn.
  • pedagogical — misconceptions, 5E strategies, teaching moves. The moat.
  • exemplar — whole strong reference lessons used as examples. Tag each with its framework (5E, gradual_release, inquiry) so it is only shown for lessons of that framework.
  • local_context — local hooks: paddy fields, goats, the monsoon, festivals.

Three ways to add

Guided — fill one form to add a single record. No JSON needed; start here.
Bulk (JSONL) — paste or upload many records at once. JSONL is just one JSON object per line, each with at least a "text" field, e.g.
Book (Markdown) — paste or upload a whole chapter. A structure-aware chunker splits it while preserving the heading hierarchy (a chunk knows it came from “Chapter 2 › Biotic Components”). Preview the split and tune it before saving.

{"text": "Students often think clouds are alive because they move.", "grade": 6, "subject": "Science"}

Add vs. update: records are keyed by their content. Submitting the same text again updates it in place — it never creates a duplicate. To fix a record, delete it below and re-add the corrected version (or just re-add if only the metadata differs and the text is new).
